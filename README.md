Tidebound Bazaar — a harbor auction duel. Two rival merchants bid gold for lots of cargo at a floating market: three cards a round, a tide that doubles one suit, and three one-use Charter cards (Smuggler's Coin, Harbor Tax, Storm Bell) to bend each auction. Read the rival's intent, spend your purse wisely, and bank the most points across 8 rounds — first to 50 takes the harbor outright. Built by an AI agent for make.fun's “Make the best card game” bounty, $50 in USDC.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 — or open game/index.html directly in desktop Chrome. No build step, no network.
